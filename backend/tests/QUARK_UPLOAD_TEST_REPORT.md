### API 端点

## 🎯 核心功能

### 1. 单文件上传
```python
POST /api/quark/upload
{
  "book_id": "xxx",
  "remote_folder": "/我的电子图书馆",
  "create_share": true,
  "share_expire": 0
}
```

**功能**:
- 上传单个 PDF 文件到夸克网盘
- 自动创建远程文件夹
- 可选创建分享链接
- 更新数据库中的上传状态

### 2. 按标签批量上传
```python
POST /api/quark/upload-by-tag
{
  "tag": "哲学",
  "book_ids": ["id1", "id2"],
  "remote_folder": "/我的电子图书馆",
  "share_expire": 0
}
```

**功能**:
- 按标签筛选书籍
- 批量上传到指定文件夹
- 自动跳过已上传的书籍
- 为整个文件夹创建分享链接

### 3. 文件夹管理
```python
# 自动创建文件夹层级
ensure_remote_folder("/我的电子图书馆/哲学/古希腊")
```

**功能**:
- 递归创建文件夹
- 检查文件夹是否存在
- 支持多层嵌套

## 🔒 安全建议

### 1. Cookie 安全
- ✅ Cookie 存储在本地，不上传到服务器
- ⚠️ Cookie 文件未加密，建议添加加密
- ⚠️ Cookie 可能过期，建议定期刷新

### 2. 分享链接安全
- ⚠️ 默认无密码分享，建议设置密码
- ⚠️ 默认永久有效，建议设置过期时间
- ✅ 可以在前端设置过期时间

### 3. 文件访问控制
- ✅ 只能访问自己上传的文件
- ✅ 需要有效的 Cookie 才能操作
- ✅ API 有错误处理和验证

## 📝 使用建议

### 1. 首次使用
1. 在前端设置页面配置 Cookie
2. 点击"测试连接"验证配置
3. 选择要上传的书籍或标签
4. 点击"开始上传"

### 2. 批量上传
- 建议按标签分组上传
- 避免一次性上传过多文件
- 注意网络连接稳定性

### 3. 分享管理
- 定期检查分享链接状态
- 及时清理不需要的分享
- 为敏感文件设置密码和过期时间
